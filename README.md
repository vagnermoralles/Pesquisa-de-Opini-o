## ⛳ OBJETIVO
Foi desenvolvido para uma pesquisa de satifação de uma empresa. O programa coleta os dados de nome, idade e opinão do usuário (1: Excelente, 2: Bom ou  3: Ruim) e cálcula a quantidade de respostas Excelentes e Ruins.

## TECNOLOGIA 
- 🐍 **Linguagem:** Python 3.
- 🔀 **Controle de Versão:** Git & GitHub.

## 🚀 Como Executar o Programa
**Pré-requisitos:** É necessário ter o [Python 3](https://www.python.org/) instalado no computador.
